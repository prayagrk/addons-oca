1. Install the module.
2. Go to **Settings → Users & Companies → Roles** and open a role.
3. In the **Model Access** tab, find the model you want to restrict.
4. Uncheck **Archive Access** to prevent archiving, or **Unarchive Access**
   to prevent unarchiving.
5. Save the role. The Archive / Unarchive options will disappear from the
   action menus for users with this role, and server-side enforcement will
   block any direct write to the `active` field as well.
